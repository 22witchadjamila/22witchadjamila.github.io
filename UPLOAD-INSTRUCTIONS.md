# Witcha Francisco Digital Portfolio — GitHub Pages upload

This folder is a static GitHub Pages website. It keeps your existing README.md and adds an `index.html` homepage plus the `assets` folder with the evidence PDFs and mock-interview MP4.

## Upload to your existing repository

1. Download and extract `Witcha_Francisco_Digital_Portfolio_2026.zip`.
2. Open https://github.com/22witchadjamila/22witchadjamila.github.io
3. Select **Add file → Upload files**.
4. From the extracted `Witcha_Portfolio_Site` folder, upload `index.html` and the complete `assets` folder. Keep the existing `README.md`; do not delete it.
5. Commit the upload to the `main` branch with a message such as `Add PRP digital portfolio website and evidence`.
6. Open **Actions** in the repository and confirm the Pages deployment workflow completes successfully.
7. Visit https://22witchadjamila.github.io/ and hard-refresh the page.

The GitHub Pages source should remain `Deploy from a branch`, branch `main`, folder `/(root)`.
