# Witcha Francisco — Digital Portfolio 2026

The website entry point is `index.html`. It uses static HTML, CSS and a small JavaScript file, so it can be hosted directly by GitHub Pages without a build tool.

## Files
- `index.html` — complete portfolio and navigation
- `assets/styles.css` — responsive visual design
- `assets/site.js` — mobile navigation behavior
- `assets/evidence/` — assessment evidence PDFs and reflections
- `assets/video/mock-interview.mp4` — compressed video evidence

See `UPLOAD-INSTRUCTIONS.md` for the publishing steps.
